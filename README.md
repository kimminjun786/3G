# 3공화국에서 살아남기 — 이미지 인덱스

1970년대 한국 정치·사회·생존 시뮬레이션용 다크 한국 웹툰풍 이미지 모음.

## 확인 범위와 파일 현황

- 최종 전수 확인: **2026-10-13**. 저장소의 번호 이미지 **203장**과 기존 제작 묶음의 **109번·171번**을 합쳐 **1~205번 전부의 실제 화면·상황명·구도**를 확인했다. 번호 없는 UI 이미지 1장도 별도 확인했다.
- 저장소에는 현재 `109.png`, `171.png`가 없다. 두 번호를 재사용하지 않으며, 아래에는 누락 상태로 표시한다. 파일을 복구 업로드했다는 뜻은 아니다.
- 번호 외 파일: `file_0000000016d88206a9ceae8126a3a9fa.png` — ‘사이트 확인’ UI. 번호 이미지와 파일 해시가 다른 별도 이미지다.
- 1~205번 중 **198장: 1536×1024**, **82~86번: 1024×1536**, **124번: 1341×1173**, **126번: 1484×1060**. 전체가 3:2라는 이전 안내를 정정했다.
- 분석은 이미지에 보이는 주제·복식·장비·문구·구도에 대한 시각 검토다. 모든 계급장·차량 모델·총기 구조·실측 도면을 사료와 대조한 정밀 감정은 아니다.

## 시대 구분과 공용 사용

작품명은 《3공화국에서 살아남기》지만, 콘텐츠는 제3공화국과 유신 이후 제4공화국까지 포함한다. 1963~1972년 장면과 1974~1976년 장면을 동일 연도로 사용하지 않는다. 82~86번은 날짜가 고정된 프롤로그이며 범용 사건 카드가 아니다.

인물은 대체로 검은 얼굴 음영을 사용하며 1번 박정희, 82~87번 일부 실존 인물 표현은 예외다. 초기 인물 카드에는 직함·문구가 많고, 최근 사건 카드는 왼쪽 아래 상황명만 들어간다. 낮/맑은 날보다 밤·폭우·황혼 비중이 높다.

## 전수 분석 결과와 우선 보완점

### 이미 충분한 장면

- 관료·정치인·직업 인물: 1~81번에 다수 확보. 신규 정장 인물만 늘리는 것보다 사건 변화가 필요하다.
- 행정 업무·병영 생활·경찰 내부: 102~159번에 폭넓게 확보. 빈 사무실·접수·보고·문서 처리 중복을 줄인다.
- 검거·연행·급습: 166~170, 186~193, 199번에 집중. 다음 제작에서는 사건 원인·진행 단계가 다른 장면을 선택한다.
- 대피·봉쇄: 135, 163, 172, 181, 194, 196, 197, 203번 존재. 동일한 계단 대피나 정문 봉쇄를 반복하지 않는다.
- 화재·구조: 101, 162, 179, 180번 존재. 추가한다면 시설·위험 종류가 다른 산업시설로 한정한다.

### 상대적으로 부족한 장면

- 군: 항공 긴급상황, 강 도하, 야외 통신선 복구, 기갑 이동.
- 경찰: 호송수단 공격, 옥상 차단, 무기 보관시설 위기, 시민 대피 유도.
- 중정: 문서 탈취·증거 현상처럼 정보 획득/유실 단계의 사건.
- 청와대: 정전, 응급 진료, 접견장 돌발상황.
- 정부 시설: 교환망 장애, 비상전력 복구, 고위직 강제 퇴장.
- 북한: 기존 200~205번은 동원·지휘·해안·검문·수송에 집중. 방공·해안포·군수공장·철교·내부 숙청·갱도 사고가 부족하다.

### 고증·표현 수정 우선순위

1. **82·85·86번:** 1963/1972/1974년 자막과 완성된 여의도 국회의사당풍 건물이 충돌한다. 1975년 준공 기록에 맞춰 배경을 수정하거나 해당 건물을 지워야 한다. 작품 속 자막 자체를 임의로 바꾸지 않았다.
2. **84번:** 1968년 서울 컷에 남산타워가 보인다. 송신탑은 1969년 착공 기록이므로 해당 컷 배경 수정이 필요하다. 후기 청와대풍 배경도 재검토 대상이다.
3. **8번 및 초기 청와대 배경:** 1991년 신본관과 유사한 대칭 한옥 지붕이 보이는 컷은 1970년대 구본관으로 단정할 수 없다. 실내만 사용하거나 배경을 교체하는 것이 좋다.
4. **57번:** ‘공보부장관’은 그림의 기존 제목이다. 1970년대 사용 시 당시 부처 명칭과 맞는지 별도 검토해야 한다.
5. **105번:** 포니 유사 차체는 초기 1970년대 범용차로 사용하지 않는다. 제조사 연혁상 포니 4도어는 1975년 12월 등장하므로 후반기 장면에 배치한다. 생성 차량을 정확한 특정 모델로 인증하지 않는다.
6. **95·124·126·131·136·200·204번:** 지역/건물의 이름과 모티브는 식별되지만 실제 배치·비례·주변 스카이라인의 정밀 복원이 아니다.
7. **제복·무기·문양:** 시대풍 단색 군복·구형 철모·짙은 경찰복·아날로그 장비는 보이나, 모표·흉장·계급장·포 구조·국기 괘 위치까지 완전 고증된 자료로 쓰지 않는다. 87번 문양을 공식 정부 인장으로 표기하지 않는다.
